# Kate Hwang Public Resume

GitHub Pages에서 바로 호스팅할 수 있는 정적 웹 이력서입니다.

## 구성 파일

- `index.html` : 이력서 본문
- `style.css` : 반응형 스타일
- `.nojekyll` : GitHub Pages에서 Jekyll 처리를 건너뛰기 위한 파일

## GitHub Pages 배포 방법

1. GitHub에서 새 Repository를 생성합니다.
2. 이 ZIP 파일의 압축을 푼 뒤 모든 파일을 Repository 최상위 경로에 업로드합니다.
3. Repository의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 GitHub Pages 주소에서 웹 이력서를 확인할 수 있습니다.

## 공개 이력서 기준

전화번호, 이메일 주소, 사진, 상세 주소 등 개인정보는 포함하지 않았습니다.
필요한 경우 LinkedIn 또는 GitHub 같은 공개 프로필 링크만 직접 추가해 사용할 수 있습니다.
